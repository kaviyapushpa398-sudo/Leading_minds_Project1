# Leading_minds_Project1

💻 Laptop Price Prediction using Multiple Linear Regression

📌 Project Overview

This project focuses on predicting laptop prices based on their specifications using the Multiple Linear Regression algorithm. The model analyzes various laptop features such as company, processor, RAM, storage, operating system, graphics card, screen resolution, and weight to estimate the laptop's market price.

The project demonstrates the complete machine learning workflow, including data preprocessing, exploratory data analysis, feature engineering, model development, prediction, and performance evaluation.

---

🎯 Objective

The primary objective of this project is to develop a Multiple Linear Regression model capable of predicting laptop prices accurately based on multiple input features.

---

📂 Dataset Information

Dataset: Laptop Prices Dataset

The dataset contains information about different laptop models and their specifications.

Features Used

- Company
- Product
- TypeName
- Inches
- ScreenResolution
- CPU
- RAM
- Memory
- GPU
- OpSys
- Weight
- Price_euros (Target Variable)

Target Variable

Price_euros

The model predicts the laptop price in Euros based on the given specifications.

🔄 Machine Learning Workflow

1. Data Collection

Loaded the Laptop Prices dataset into a Pandas DataFrame.

2. Data Exploration

- Displayed dataset records
- Examined dataset structure
- Analyzed feature distributions

3. Data Cleaning

- Checked missing values
- Removed unnecessary columns
- Ensured data consistency

4. Feature Selection

Selected meaningful input features that influence laptop prices.

5. Encoding Categorical Variables

Applied Label Encoding to convert categorical features into numerical values suitable for machine learning algorithms.

6. Exploratory Data Analysis (EDA)

Performed:

- Distribution Analysis
- Correlation Analysis
- Data Visualization

7. Model Development

Implemented Multiple Linear Regression using Scikit-learn.

8. Model Training

Split the dataset into:

- Training Set (80%)
- Testing Set (20%)

9. Model Prediction

Generated price predictions using the trained model.

10. Model Evaluation

Evaluated model performance using regression metrics.
